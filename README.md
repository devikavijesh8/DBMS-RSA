# Object Oriented Database (OODBMS)

## About the Presentation

This presentation is about Object Oriented Database Management Systems (OODBMS) and why they are useful in applications that work with complex data.

It covers the basic concepts of object-oriented databases, the problems faced by traditional relational databases when handling complex data, and how object-oriented concepts can help solve these problems.

## Topics Covered

- Introduction to Object Oriented Databases
- Objectives of OODBMS
- Limitations of relational databases
- Need for object-oriented databases
- Evolution and structure of object-oriented databases
- Object-relational database systems
- Complex data types with an Address example
- SQL queries using complex data types
- Multivalued attributes using a Book example
- Key takeaways

## What I Learned

Relational databases store data mainly in tables, which can become complicated when dealing with complex objects, inheritance, and multivalued attributes.

Object-oriented databases help represent such data using concepts like objects, inheritance, encapsulation, object identity, and polymorphism. Object-relational database systems also combine relational database features with some object-oriented concepts.

The presentation includes examples of complex data types and SQL queries to show how these concepts can be used in database design.

## Purpose

The purpose of this presentation is to understand the basic idea behind object-oriented databases, their advantages, and how they differ from traditional relational database systems.
